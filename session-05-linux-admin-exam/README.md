# Linux Administration Exam

DataScientest Linux Systems Administration DevOps practical examination.

## Objective

Deploy a production-style web environment using:

- Nginx
- PHP 8
- WordPress
- MariaDB
- DNS
- Let's Encrypt SSL
- automated backups

## Structure

- `scripts/` - administration and backup scripts
- `config/` - safe configuration copies
- `notes/` - exam notes and documentation
- `backups/` - local backups, excluded from Git
